Masks Eye uwu

-Puzzewgame waaw je maskews gebwuikt ♡-

Tijdens dit pwoject wewkte ik samen in een team met zowew awtists aws devewopews aan een 3-daagse game jam, waawin we een puzzewspew ontwikkewden genaamd Mask's Eye. Het spew dwaait om het wandgoed van Wobewt Scewewitas, waawin spewews maskews moeten vewzamewen. Ewk maskew geeft unieke kwachten die nodig zijn om puzzews op te wossen en uitiendewijk de wawe moowdenaaw te ontmaskewen 🌸.

Mijn focus wag voowaw op het ontwewpen en impwementewen van de mini-games die nodig wawan om de maskews te unwocken. Eén van de meest memowabewe momenten was de waatste mini-game, waawin spewews een kameweon moesten matchen met kwewen. De eewste spewews wawen echtew kwewenbwind, waawdoow ze hewemaaw vewdwaawden wat zowgde voow een hiwawisch maaw weewzaam inzicht in spewtoegankewijkheid en ontwewpkeuzes ✩°｡⋆.

    private void FixedUpdate()
    {
        //move the segments
        for (int i = _segments.Count - 1; i > 0; i--)
        {
            _segments[i].position = _segments[i - 1].position;
        }
        //use anchoredPosition for canvas transform
        //this game was made on a canvas
        Vector2 pos = rect.anchoredPosition;
        pos += _direction * gridSize;
        rect.anchoredPosition = pos;

    }

    private void Grow()
    {
        for ( int i = 0; i <6; i++)
        {
            //grow snake up to 5 times
            Transform segment = Instantiate(segmentPrefab.transform, c.transform);
            segment.transform.position = _segments[_segments.Count - 1].position;
            _segments.Add(segment);
            
        }
    }
    private void OnTriggerEnter2D(Collider2D collision)
    {
        //grow the snake if food is eaten
        if (collision.tag == "Food")
        {
            Grow();
        }
        //respawn snake if wall is hit
        if(collision.tag == "Wall")
        {
            rect.anchoredPosition = new Vector2(0f, 0f);
        }
    }
