Ghost Shooter

-Red de wereld van geesten-

Dit project is een vervolg op het café-spel, waarin je een geest-invasie moest veroorzaken en twee NPC’s moest beschermen. Voor het eerst werkte ik met statemachines, coroutines en NavMeshAgents, wat veel leermomenten gaf over tijdsbeheer en AI-bewegingen.

Mijn focus lag op het programmeren van gameplay-mechanics in Unity. Ik gebruikte coroutines voor het spawnen van geesten en waves, Random.Range voor willekeurige spawnlocaties, en hield de game state bij zodat de speler pas faalt als beide NPC’s dood zijn.

Gameplay & Mechanics

  • Speler kan pistool, gitaar, granaat en eten gebruiken om vijanden te bestrijden en NPC’s te beschermen.
  • Healthpacks en cooldowns werken per gamemode (protect customers vs ghost invasion).

Enemy AI & Waves

  • Vijanden volgen speler en NPC’s via NavMeshAgents en coroutines, waves worden steeds moeilijker met extra health en spawn.

Health & UI

  • Player en enemy healthbars met visuele feedback, plus UI voor klantenstatus, health en pistool reload tijd.

Systems & Effects

  • Startmenu, win/game-over schermen, post-processing, geluiden en particle effects voor chaotische sfeer.

//Dit script regelt het inspawnen van de vijanden
IEnumerator SpawnWaves()
{
    for (int wave = 1; wave <= totalWaves; wave++, waveCount++) // Go through each wave
    {
        // Spawn the enemies for this wave
        for (int i = 0; i < enemiesPerWave; i++)
        {
            SpawnEnemy(); // This spawns one enemy
            yield return new WaitForSeconds(timeBetweenEnemies); // Wait for 1 second before spawning the next one
        }
        //all enemies spawned

        yield return new WaitForSeconds(timeBetweenWaves); // Wait for 5 seconds before starting the next wave
        //all waves finished

    }

    //all waves complete
}

// This function actually spawns the enemy at the spawn point
void SpawnEnemy()
{
    int ghost = Random.Range(1, 5);
    //choose which ghost to spawn
    switch (ghost)
    {
        case 1:
            ChosenGhost = enemyPrefab1;
            break;
        case 2:
            ChosenGhost = enemyPrefab2;
            break;
        case 3:
            ChosenGhost = enemyPrefab3;
            break;
        case 4:
            ChosenGhost = enemyPrefab4;
            break;
    }

    int randomLoc = Random.Range(1, 6);
    Debug.Log(randomLoc);
    //choose which location to spawn at
    switch (randomLoc)
    {
        case 1:
            newLoc = loc1;
            break;
        case 2:
            newLoc = loc2;
            break;
        case 3:
            newLoc = loc3;
            break;
        case 4:
            newLoc = loc4;
            break;
        case 5:
            newLoc = loc5;
            break;
    }

    if (ChosenGhost != null)
    {
        //spawn chosen ghost at the randomly chosen location
        spawnedGhost = Instantiate(ChosenGhost, newLoc.position, Quaternion.identity);
    }

    //depending on which wave is the current one, increase the spawned ghost health
    health increasedHP = spawnedGhost.GetComponentInChildren();
    increasedHP.maxHealth = 40f + (waveCount - 1) * 20;
}
