Disco frenzy

-Een disco-shooter met robots en een eindbaas-

In dit project werkte ik samen met andere developers en artists aan een disco shooter met robots. Het spel heeft verschillende kamers met vijanden die pickups kunnen droppen en eindigt met een baas die drie frisbees tegelijk gooit. Dit was mijn eerste echte groepsproject, waardoor ik veel leerde over communicatie en samenwerking.

Mijn focus lag op de Unity Editor en gameplay-mechanics. Ik implementeerde haptic feedback voor lopen, zwaardaanvallen, pistolen, het oppakken van objecten en schade van vijanden. Het simuleren van lopen was uitdagend, omdat het niet vanzelf stopte, maar uiteindelijk zorgde dit voor een vloeiende en interactieve spelervaring.

//Script voor het toevoegen van haptic feedback
private void Update()
{
    timer += Time.deltaTime;
    if (WalkEnabled == true)
    {
        //keep playing the walking feeling when player is walking
        if (isWalkingHaptic == false)
        {
            //play walking feeling when walking
            BhapticsLibrary.Play(BhapticsEvent.SHORTWALK);
            isWalkingHaptic = true;
            timer = 0f;
        }

        if (isWalkingHaptic == true && timer > 0.6f)
        {
            //if the walking feeling has stopped but the player is still moving in game
            //stop the walking haptic bool so that the walking feeling can be played again
            isWalkingHaptic = false;
        }
    }
    if (WalkEnabled == false)
    {
        //stop the walking feeling if the player suddenly stops moving
        BhapticsLibrary.StopByEventId("WALKING");
    }
}

private void actionPerformed(InputAction.CallbackContext context)
{
    Vector2 input = context.ReadValue();
    
    //check the stick movement
    //depending on that decide if player is walking or not
    if (input.magnitude < 0.9f)
    {
        //not walking
        WalkEnabled = false;
    }
    else if (input.magnitude > 0.9f)
    {
        //player is walking
        WalkEnabled = true;
    }
}
